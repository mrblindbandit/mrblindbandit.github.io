## Mirror vs production

- **This repository** serves public HTML/CSS/JS for browsing and demos on GitHub Pages.
- **Production** runs on **ChatGPT Sites (OpenAI Sites)** at `mrblindbandit.net` with Clerk auth, LiveKit, Worker/API, D1, and secrets.
- Clerk sign-in, LiveKit tokens, D1, and `/api/` routes are **not** available on Pages.

Do **not** describe production as “hosted on Cloudflare” as the product host.
