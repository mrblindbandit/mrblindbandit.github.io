# Security Policy

## Supported surfaces

| Surface | Status |
|---|---|
| GitHub Pages static site (`https://mrblindbandit.github.io/`) | Best-effort (static only) |
| Production on **ChatGPT Sites** (`https://mrblindbandit.net`) | Supported — prefer reporting via website `SECURITY.md` |

## Reporting a vulnerability

**Please do not open a public GitHub Issue for security bugs.**

Email **business@mrblindbandit.net** with description, repro steps, URLs, and contact details.

Optional: CC `kheckfinancial@gmail.com`.

If the issue involves Clerk, LiveKit, Worker APIs, or D1, it almost certainly belongs to production Sites — see:

https://github.com/mrblindbandit/mr-blindbandit-website/blob/main/SECURITY.md

## Secrets

Never commit secret values to this static repository.
