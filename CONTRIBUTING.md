# Contributing to mrblindbandit.github.io

This repository is the **GitHub Pages static mirror** of Blindbandit Records.

## Important

- **Canonical source** for product/HTML changes is usually [`mr-blindbandit-website`](https://github.com/mrblindbandit/mr-blindbandit-website)
- **Production** (auth, API, D1) is **ChatGPT Sites** at https://mrblindbandit.net
- Prefer PRs against the website repo unless the change is Pages-specific (e.g. `llms.txt`, Pages README)

## Rules

1. Read `AGENTS.md` and `SECURITY.md`
2. Never commit secrets
3. Do not wipe legal / privacy pages
4. Keep ChatGPT Sites vs Pages distinction accurate in docs
